1. Как выполняется поиск в связном списке?
Поиск выполняется последовательным обходом списка с начала (head). Каждый элемент сравнивается с искомым значением, пока не найдется нужный или список не закончится.


2. Почему поиск занимает O(n)?
Потому что в худшем случае нужно пройти весь список из n элементов, чтобы найти нужный или убедиться, что его нет.


3. Как удалить элемент из списка?
Нужно:
	•	найти элемент
	•	запомнить предыдущий узел
	•	изменить ссылку next у предыдущего узла
Если удаляется первый элемент — просто сдвигаем head.
